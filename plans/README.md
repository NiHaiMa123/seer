# 计划

一份计划一个文件。计划不代替 [扩展清单](../docs/extension-checklist.md)：清单是贵的那几档要改哪些文件，[触点预算](touch-budget.md) 是一条实现最多动几处。

| 文件 | 内容 |
|---|---|
| [engine-atoms.md](engine-atoms.md) | 已落地（步骤 1–5）。技能和魂印收成封闭归约器 |
| [target-route.md](target-route.md) | 已落地（步骤 1–9）。伤害 rider、被动形状、回合窗发 `periodic` |
| [touch-budget.md](touch-budget.md) | 已落地。一条实现按档改，超出上限的不要做 |
| [add-effect.md](add-effect.md) | 已落地。加一条技能或魂印的操作顺序；顺序快照已补齐 |
| [ui-redesign.md](ui-redesign.md) | 客户端视觉，另册。不由触点预算执行 |
