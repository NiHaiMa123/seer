# UI 重设计计划（主界面 / 战斗 / 仓库 / 背包）

日期：2026-10-11。只改客户端表现层（`apps/client`）。不碰战斗核心、结算、数据定义（`target-route.md` 正在改引擎，互不干扰）。

## 目标

第一眼看出是一款制作精致的现代精灵养成游戏，而不是套了玻璃主题的网页。
方向：Premium Stylized Sci-Fi Fantasy，「星际科技 × 能量晶体 × 精灵世界」。
- 深海军蓝底 + 晶体青点缀 + 少量金色（只给高价值：第五技能、首发、胜利、主 CTA）。
- 属性、技能类别、稀有度、阵营各用自己的辅助色，不全涂蓝。
- 造型：左上 + 右下切角（敌方镜像），描边沿切角走；六棱晶体用于头像、徽章、属性。
- 材质分层：玻璃（战场上的铭牌）/ 抬升面板 / 金属描边 / 晶体描边 / 金边。
- 与卡通场景融合：美术资源用 Krea2 按同一画风生成，不用写实硬科幻。

## 现状差距（审查结论）

| 页面 | 问题 |
|---|---|
| 主界面 | 黑底 + 三个 emoji 卡片，无视觉中心、无精灵、无玩家身份 |
| 战斗 | 卡通场景上叠石墨灰毛玻璃，割裂；头像是精灵 id 里的一个字母；日志灰块压场中；指令区是平板 |
| 仓库 | 200 个属性芯片堆成墙；卡片是一模一样的字母圆点 |
| 背包 | 通用面板，空状态什么都没有 |
| 战斗入口 | 纯列表 + 链接 |

## 结构

- 样式拆到 `apps/client/styles/`：`tokens.css`（色/形/字/影/动效 Token）→ `kit.css`（通用组件）→ `battle.css` → `screens.css`（主界面/仓库/背包/入口）。`index.html` 只做 link。
- 通用组件 `src/ui/kit.tsx`：`Icon`（内联 SVG）、`TypeGem`（属性晶石）、`Portrait`（六棱头像框）、`TopNav`（四分区导航）、`SceneBg`。
- 美术索引 `src/ui/art.ts`；资源在 `assets/ui/*.webp`。
- 精灵造型抽到 `src/creature.ts`，战场（`scene.ts`）与头像（`portrait.ts` 离屏 Pixi 出图）共用：卡面上就是战场上那只。

## 美术资源（Krea2，已生成）

背景：`bg_home`、`bg_lab`（仓库）、`bg_bag`（背包）、`tex_crystal`（面板纹理）。
图标（抠图 256px）：五种药剂 `item_*`、四类刻印 `seal_*`、导航 `nav_battle/storage/bag`。
原则：只做底图、纹理、图标；文字、数值、按钮、进度条全部是真实组件。

## 约束

- 所有 `data-testid` 与测试依赖的文本格式（`次数 a/b`、`.hpbar b`、`.chip` 计数、`后备×N`、`STD`）保留。
- 持续动画只留：第五技能流光、低血呼吸、出招状态点、紧急提示；其余动效只在交互时触发。`prefers-reduced-motion` 关掉。
- `backdrop-filter` 不在大面积元素上用；场景上的铭牌用半透明渐变代替。
